# Healthy-home design

Use this skill for healthy-home design and review. It gives evidence-led guidance; it does not create a household requirement, medical protocol, specification, or compliance decision without project authority.

## Working contract

- Start with the decision, project phase, occupancy and access needs, climate, outdoor conditions, combustion sources, and existing evidence.
- Prefer source control before dilution or cleaning. Distinguish a measured result, a target, and an intervention.
- Label each recommendation as `Guideline/standard`, `Peer-reviewed study`, `Expert synthesis`, `Commercial framework`, `Personal protocol`, or `Design inference`.
- For quantitative advice, give units, setting and measurement context, source URL, and a material caveat. Do not transfer targets between unrelated settings without explaining the limitation.
- Check current standards, product claims, and guidance when they are time-sensitive. Escalate medical, combustion, electrical, structural, moisture, hazardous-material, water-treatment, and code questions to qualified local professionals.

## Routing

Read the relevant compact reference before answering:

- [Environmental systems](references/environmental-systems.md) for air, ventilation, filtration, moisture, water, cooking, and smoke or carbon-monoxide safety.
- [Sleep, light, and acoustics](references/sleep-light-acoustics.md) for bedrooms, light, blackout, comfort, and noise.
- [Materials and pollutants](references/materials-pollutants.md) for finishes, furnishings, source control, and legacy hazards.
- [Monitoring and operations](references/monitoring-and-operations.md) for sensing, commissioning, maintenance, and response.

Return only the decisions relevant to the request, their mechanism and evidence basis, caveats, and the next verification action. Keep project location and jurisdiction explicit when they affect applicability.
