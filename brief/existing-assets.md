# Bunuri existente

Acest fișier inventariază bunurile deținute care se aduc în casa nouă și condițiile lor de integrare. Catalogul bugetar
nu le bugetează din nou ca achiziții identice.

| ID       | Decizie                                                                                                        |
| -------- | -------------------------------------------------------------------------------------------------------------- |
| `AST-01` | Bunurile enumerate se reutilizează și nu se bugetează din nou ca achiziții identice.                           |
| `AST-02` | Proiectarea coordonează amplasarea, dimensiunile, alimentarea, degajările și mentenanța fiecărui bun relevant. |

## La roșu

Geometria casei ține cont de gabaritele bunurilor care cer spațiu dedicat, conform trimiterilor din inventar.

## La gri

Alimentările și suporturile necesare bunurilor din inventar sunt executate conform încăperilor în care se amplasează.

## La cheie

Finisajele și mobilierul fix sunt pregătite pentru amplasarea bunurilor fără improvizații.

## Extra

Bunurile existente se întrețin sau se înlocuiesc numai după evaluarea stării și a compatibilității lor.
