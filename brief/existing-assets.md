# Existing assets

| ID | Status | Decision |
| --- | --- | --- |
| `AST-01` | `deferred` | Record only verified existing assets, their condition, ownership, compatibility, and intended project role. |
| `AST-02` | `preferred` | Keep movable possessions distinct from fixed works and their construction budget scope. |
| `AST-03` | `deferred` | Confirm reuse, storage, disposal, warranties, and installation requirements before relying on an asset. |

`NOTE-AST-04` This template contains no inherited inventory, invoices, warranties, suppliers, or ownership records.
