# Exterior

Acest fișier deține grădina, terasa, accesul, parcarea, împrejmuirea și traseele exterioare. Amplasările sunt alegeri
ale gospodăriei în cadrul retragerii din [Arhitectură](architecture.md) (`SITE-02`) și se verifică prin proiect.

| ID       | Decizie                                                                                                                                                                    |
| -------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `GAR-07` | Exteriorul este simplu, robust și ușor de întreținut: nu se construiesc piscină, carport sau construcții anexe. Amenajările rămân reparabile și accesibile intervențiilor. |

## La roșu

Terasamentele generale și nivelarea terenului în jurul casei se execută odată cu fundațiile, cu pante care îndepărtează
apa de fațade.

## La gri

| ID       | Decizie                                                                                                                                                                                                                                                                |
| -------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `GAR-06` | Traseele îngropate de apă, canalizare, electricitate și date se execută într-o singură campanie, înaintea pavajelor și gazonului, cu separările și adâncimile stabilite pe utilități (`EN-08`). Se pozează și alimentarea iluminatului exterior și a porții pietonale. |

## La cheie

| ID       | Decizie                                                                                                                                                                                                                                                                                          |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `GAR-02` | Laturile casei fără terasă au trotuar perimetral îngust, pavat, cu pantă spre exterior, care protejează soclul și permite mentenanța fațadelor.                                                                                                                                                  |
| `GAR-03` | Terasa din dreptul livingului este descoperită, pavată cu dale exterioare antiderapante, la nivelul pardoselii interioare cu prag compatibil cu ușa vitrată, și păstrează retragerea din `SITE-02`. Dimensiunile permit o masă exterioară pentru șase persoane.                                  |
| `GAR-04` | Accesul din stradă și locul de parcare descoperit pentru un autoturism sunt pavați cu pavaj permeabil sau cu rosturi drenante; aleea pietonală leagă poarta pietonală de ușa de intrare fără a traversa locul de parcare.                                                                        |
| `GAR-05` | Parcela are gard perimetral; pe latura străzii, gardul are o poartă pietonală și o poartă auto pentru locul de parcare, cu înălțimea și transparența verificate față de regulamentul local de urbanism. Comanda porții pietonale este definită în [Casă inteligentă](smart-home.md) (`TECH-10`). |

## La mutat

| ID       | Decizie                                                                                                                                                                  |
