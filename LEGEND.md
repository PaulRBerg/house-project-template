# Legend

| Term          | Meaning                                                                 |
| ------------- | ----------------------------------------------------------------------- |
| `required`    | An accepted outcome to preserve until replaced by an explicit decision. |
| `preferred`   | An accepted default; record a reason for a material departure.          |
| `phased`      | An accepted future intention that may sit outside initial delivery.     |
| `deferred`    | An open decision awaiting evidence or a later decision.                 |
| La roșu       | Early construction and enabling work stage.                             |
| La gri        | Building completion and service-installation stage.                     |
| La cheie      | Finishes and fixed fit-out stage.                                       |
| La mutat      | Move-in, external completion, and close-out stage.                      |
| Base estimate | The current cost basis before forecast adjustments.                     |
| Forecast      | The planned future amount after the budget's documented adjustments.    |
