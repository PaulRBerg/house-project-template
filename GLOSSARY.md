# Acronym Glossary

This is a concise reference for building-performance, healthy-home and Romanian permitting terms used in the household
brief and the project skill references. It describes project usage, not requirements or professional advice.

## Energy and building services

| Term | Meaning in this repository                                                                                                                                                                                                                                                                  |
| ---- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| nZEB | Nearly Zero-Energy Building: the Romanian legal energy-performance compliance regime and the project's legal floor (`SITE-08`). It is distinct from Passive House.                                                                                                                          |
| PHI  | Passive House Institute: a term appearing only in third-party evidence and benchmark values (including the Casa Buhnici certified record and the PHI benchmark table in `building-science`); this project contracts no Passive House or other voluntary certification (`SITE-08`, `EV-06`). |
| PHPP | Passive House Planning Package: a third-party Passive House energy-modeling and benchmark term; its calculated outputs are not utility-bill predictions.                                                                                                                                    |
| TFA  | Treated Floor Area: a PHPP-defined boundary appearing only in third-party evidence and benchmark values; it is not the same as cadastral, useful, gross, or footprint area.                                                                                                                 |
| HVAC | Heating, Ventilation, and Air Conditioning: the coordinated indoor-climate systems.                                                                                                                                                                                                         |
| MVHR | Mechanical Ventilation with Heat Recovery: the house's balanced supply-and-extract ventilation system (`EN-05`, `EN-06`); HRV and ERV name its sensible and enthalpy exchanger variants.                                                                                                    |
| HRV  | Heat-Recovery Ventilation: balanced mechanical ventilation that transfers heat between exhaust and supply air.                                                                                                                                                                              |
| ERV  | Energy-Recovery Ventilation: balanced mechanical ventilation that can transfer both heat and moisture. The appropriate HRV/ERV choice remains a design decision.                                                                                                                            |
| HRE  | Heat-Recovery Efficiency: a reported measure of a ventilation unit's heat recovery under defined test conditions, not a delivered whole-house result.                                                                                                                                       |
| DHW  | Domestic Hot Water (Romanian ACM, apă caldă menajeră): the hot-water system for taps, showers, and similar uses (`EN-04`).                                                                                                                                                                  |
| PV   | Photovoltaic: solar-electric generation (`EN-07`). Panel count or nominal capacity alone does not establish output.                                                                                                                                                                         |

## Indoor environment

| Term  | Meaning in this repository                                                                                                            |
| ----- | ------------------------------------------------------------------------------------------------------------------------------------- |
| IAQ   | Indoor Air Quality: the overall quality of indoor air, informed by ventilation, filtration, source control, moisture, and monitoring. |
| CO₂   | Carbon dioxide: used here only as a ventilation proxy, never as proof of overall IAQ (`EN-11`).                                       |
| PM2.5 | Fine particulate matter with an aerodynamic diameter of 2.5 micrometres or less.                                                      |

## Romanian permitting and construction

| Term      | Meaning in this repository                                                                                                                                                                                          |
| --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| CU        | Certificat de urbanism: the planning certificate that states the local urbanism rules for a parcel. Until it is issued, setbacks, height regime, POT and CUT remain project-specific unknowns (`SITE-03`, `HH-05`). |
| PUG / PUZ | Plan Urbanistic General / Zonal: the general or zonal urban plan whose regulations the CU applies to the parcel.                                                                                                    |
| POT / CUT | Procentul de ocupare a terenului / coeficientul de utilizare a terenului: the plot-coverage percentage and floor-area ratio set by the local urbanism rules.                                                        |
| BCA       | Beton celular autoclavizat: autoclaved aerated concrete blocks, allowed only in secondary elements (`SITE-04`).                                                                                                     |
| P+1       | Parter plus one upper floor: the house's level count (`SITE-03`).                                                                                                                                                   |
